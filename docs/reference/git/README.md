# Git credential reference

Official Git documentation, copied unmodified in its upstream AsciiDoc format.

- [gitcredentials](gitcredentials.adoc): credential contexts, helper configuration, `useHttpPath`, and custom helper behavior. Published manual: https://git-scm.com/docs/gitcredentials. Source: https://github.com/git/git/blob/master/Documentation/gitcredentials.adoc.
- [git-credential](git-credential.adoc): companion plumbing manual defining the helper input/output protocol. Published manual: https://git-scm.com/docs/git-credential. Source: https://github.com/git/git/blob/master/Documentation/git-credential.adoc.

These snapshots come from Git's `master` branch. Check compatibility with the supported Git versions before using newer protocol attributes.
